Contained Mechanics
Interaction System
A system that allows the player to interact with objects and NPCs in the environment.

Customer AI Behavior Tree

Random customer NPCs spawn.

Each selects a random table.

Performs a specific task at the table.

Leaves the area after completing the task.

Random Interactable NPC Spawning
Random interactable NPCs spawn in the world for the player to engage with.

Dialogue Popup and Selection UI
A dialogue window appears when interacting with NPCs, allowing the player to make choices and assign tasks to them.

Item Pickup System
The player can pick up items from the ground.

Inventory System

Picked up items are added to a Minecraft-style 4-slot HUD inventory.

The player can use or drop items from the inventory.
